# To_Do_API

This repo holds the API for the REACT application To_Do at https://github.com/YomNom/To_Do. This API implements standard CRUD interface using standard HTTP methods. 

# Install

It is highly recommended to have this repo in the same directory as the [frontend](https://github.com/YomNom/To_Do):
> to_do_dir/
>
> ├── To_Do/             
> └── To_Do_API/

## Packages

Implemented with:

- Node.js (v22)
- Express.js
- CORS
- JSON Body Parser
